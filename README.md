# Dancing Robot 🤖

**Timeline:** December 2020 - March 2021

A fun, interactive robot built with Arduino and C++ that is capable of walking and dancing. This project integrates multiple sensors and motors to execute programmed movement patterns and interact with its environment.

## 🚀 Features
* **Programmed Movements:** Capable of walking and executing custom dancing sequences.
* **Sensor Integration:** Utilizes sensors for motion and environmental interaction.
* **C++ Logic:** Core behavior is fully programmed using the Arduino IDE.

## 🛠️ Technologies & Components
* **Microcontroller:** Arduino physical computing platform
* **Language:** C++
* **Hardware:** Motors, interactive sensors, and an Arduino I/O board
  

**Arduino** is an open-source physical computing platform based on a simple I/O board and a development environment that implements the Processing/Wiring language. This project showcases a basic interactive robot capable of movement patterns like dancing and walking.

## ⚙️ Getting Started

1. Clone this repository to your local machine.
2. Open the `mino_robo_ncom.ino` file in the Arduino IDE.
3. Connect your Arduino board to your computer via USB.
4. Verify the code and upload it to your board.
5. Power up the robot and watch it dance!
